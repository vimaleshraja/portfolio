# Vimalesh Raja Portfolio

A simple, responsive portfolio website built with HTML, CSS, and JavaScript.

## Features
- Dark/Light mode toggle
- Responsive design
- Sidebar navigation with active section highlighting
- Sections: About, Experience, Projects, Skills, Education

## Structure
- `index.html`: Main HTML file
- `css/style.css`: Stylesheet
- `js/script.js`: JavaScript for theme toggle and active section tracking
- `images/`: Image assets
- `resume.txt`: Resume text file

## Usage
Open `index.html` in a web browser to view the portfolio.
